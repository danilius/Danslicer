# Task 04b slider and scrub policy audit

All production numeric drag hosts were inventoried from Views/*.axaml, Controls/*.axaml and code-created fields. The control gallery remains a deliberately local transaction demonstration. Filled fields retain absolute actual-track mapping, Shift fine adjustment and centered value/unit. Model fields remain relative scrubs. Display and committed edits use at most two decimals; integer fields remain integral. Typed expressions are validated before commit; invalid text leaves the last valid scene state intact. No drag starts support generation, slicing, export or file writes.

## Persistence and lifecycle

The preview object is ended once and ignores subsequent updates/commit/cancel. ScrubField owns capture and restores on Escape, capture loss, detach, external value/context/lock changes, hidden layout, selection/workspace changes and window deactivation/close. A completed preview suppresses the old commit handler to prevent duplicate saves. Config and transform final callbacks see restored originals, not already-previewed values. No-op gestures restore without saving/undo. New pointer ownership cancels any previous numeric gesture.

AppConfig.Save and injected ConfigViewModel saving paths temporarily serialize the original value of every active config preview, then silently put preview values back. This prevents leakage into an unrelated config save. Project Save cancels the active numeric gesture before serialization. Workspace-ui.json storage/order events are unchanged. PreviewPersistence is thread-local; production mutation and coalesced raft ticks run on the UI thread. No background preview jobs were introduced. A raft tick rebuilds only the current request; it cannot overlap another tick, and stop/clear on completion prevents late work.

## Cost evidence and practical bounds

Actual native profile (outline plus mesh, 7 warm samples): Plate 15 feet median 2.54 ms/max 6.83; Web 15 median 1.36/max 2.10; Plate 600 median 58.10/max 82.60; Web 600 median 20.99/max 28.60. Thus raft work is coalesced to a 100 ms timer rather than every pointer event. A very large individual rebuild can still block the UI; there is no hard per-frame time guarantee. Rendering settings reuse the task-04 renderer, including its shadow-map costs; no shader/effect redesign. Exact final computation remains synchronous. These synthetic measurements are host-specific, not a full-job benchmark.
